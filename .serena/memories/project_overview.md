# Project Overview

## Purpose
This is a Python project called "parity-check" designed to create a Streamlit web application for teaching parity check concepts. The project is specifically designed for educational purposes, likely for high school computer science students learning about data error detection and correction.

## Tech Stack
- **Framework**: Streamlit (web application framework)
- **Language**: Python 3.11
- **Dependencies**: streamlit, pandas
- **Development Environment**: Dev Container using Python 3.11 on Bullseye
- **IDE**: VS Code with Python and Pylance extensions

## Current State
The project is in its initial state with:
- A basic Streamlit app file (`streamlit_app.py`) with minimal content
- Requirements file specifying dependencies
- Dev container configuration for consistent development environment
- The app automatically runs on port 8501 when the container starts
